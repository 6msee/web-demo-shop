# web-demo-shop — MARBO98 (ร้านค้าหลายหมวด + หลังบ้าน CMS)

ร้านออนไลน์สำหรับกลุ่มวัยรุ่น–วัยทำงาน (13–40 ปี) รองรับสินค้าได้ทุกประเภท เช่น เครื่องดื่ม ขนม แฟชั่น แก็ดเจ็ต บิวตี้ และไลฟ์สไตล์

หน้าแรกมีฉาก 3 มิติด้วย Three.js เป็นวงโคจรของสินค้าแนะนำ หมุนตามการเลื่อนจอหรือลากเมาส์ และคลิกสินค้าเพื่อเปิดดูได้ หลังบ้าน CMS ใช้ฐานข้อมูล **Supabase**

**ส่วนต่างๆ ของหน้าร้าน:**
- หมวดหมู่
- แนะนำ (bento)
- ขายดีที่สุด (จัดอันดับจากยอดสั่งซื้อจริง)
- แบนเนอร์โปรโมชัน
- มาใหม่
- สินค้าทั้งหมด (กรอง ค้นหา และเรียงลำดับได้)
- หน้ารายละเอียดสินค้า (หลายรูป หลายตัวเลือก มีราคาก่อนลด)

- หน้าร้าน: `http://localhost/web-demo-shop/`
- หลังบ้าน: `http://localhost/web-demo-shop/admin/`

ต้องเปิด Apache ใน XAMPP และเข้าผ่าน `http://localhost` เท่านั้น ถ้าดับเบิลคลิกเปิดไฟล์ตรงๆ JavaScript modules จะไม่ทำงาน

## เริ่มใช้หลังบ้านครั้งแรก
1. เข้า `/admin/` แล้วกด **"สมัครผู้ดูแล"**
2. **บัญชีแรกที่สมัครจะได้สิทธิ์เจ้าของร้าน (owner) อัตโนมัติ** ส่วนบัญชีถัดไปเป็น "รออนุมัติ"
3. Supabase จะส่งอีเมลยืนยัน ให้กดลิงก์ในอีเมลก่อน แล้วกลับมาเข้าสู่ระบบ
4. เจ้าของร้านให้สิทธิ์คนอื่นได้ที่เมนู **ผู้ดูแลระบบ**

## เมนูในหลังบ้าน
| เมนู | ทำอะไรได้ |
|---|---|
| แดชบอร์ด | ยอดขายวันนี้และ 7 วัน, ออเดอร์รอชำระ, กราฟ 14 วัน, สินค้าขายดี, สต็อกใกล้หมด |
| คำสั่งซื้อ | กรองตามสถานะ, ค้นหา, เปลี่ยนสถานะ (รอชำระ → ชำระแล้ว → จัดส่ง → สำเร็จ / ยกเลิก), บันทึกภายใน, พิมพ์ใบสั่งซื้อ, ส่งออก CSV, แจ้งเตือนออเดอร์ใหม่แบบเรียลไทม์ |
| สินค้า & สต็อก | สินค้าทุกประเภท, หลายรูปต่อสินค้า (จัดลำดับได้), แท็ก, ติดดาว “แนะนำ”, ตัวเลือก (ไซซ์/สี/ขนาด/รุ่น) พร้อมราคา ราคาก่อนลด สต็อก และรูปของแต่ละตัวเลือก |
| หมวดหมู่ | เพิ่ม/แก้/ลบ/ซ่อนหมวด, สีการ์ด, รูปประจำหมวด, ลำดับ |
| เนื้อหาหน้าเว็บ | Hero + ข้อความวิ่ง, แบนเนอร์โปรโมชัน, หัวข้อทุกส่วน |
| คลังรูปภาพ | อัปโหลด (ลากวาง), คัดลอก URL, ลบ (รูปใหญ่ถูกย่อเป็น WebP อัตโนมัติ) |
| ตั้งค่าร้าน | ชื่อร้าน, LINE OA ID, ประกาศ, ส่วนลดเมื่อซื้อสินค้าต่างแบบครบ N ชิ้น, ค่าจัดส่ง |
| ผู้ดูแลระบบ | (เฉพาะเจ้าของร้าน) อนุมัติ เปลี่ยนสิทธิ์ หรือถอนสิทธิ์ผู้ดูแล |

## ฐานข้อมูล (Supabase project: `web-demo-shop`, ภูมิภาค Singapore)
| ตาราง | เก็บอะไร |
|---|---|
| `settings` | ค่าตั้งร้าน (มี 1 แถว) |
| `content_blocks` | ข้อความแต่ละส่วนของหน้าเว็บ (JSON) |
| `categories` | หมวดหมู่สินค้า |
| `products`, `product_sizes` | สินค้า (รูปหลายรูป แท็ก แนะนำ) และตัวเลือก (ราคา ราคาก่อนลด สต็อก รูป) |
| `orders`, `order_items` | คำสั่งซื้อและรายการสินค้า |
| `profiles` | ผู้ดูแลและสิทธิ์ (owner / staff / pending) |
| Storage `media` | รูปที่อัปโหลดจากหลังบ้าน |

**ความปลอดภัย:**
- ทุกตารางเปิด Row Level Security คนทั่วไปอ่านได้เฉพาะสินค้าและเนื้อหาที่เปิดแสดง
- คำสั่งซื้อสร้างผ่านฟังก์ชัน `place_order` เท่านั้น ฟังก์ชันนี้**คำนวณราคา ส่วนลด และค่าส่งใหม่ที่ฐานข้อมูล** และตัดสต็อกให้ ลูกค้าแก้ราคาจากหน้าเว็บไม่ได้
- ไฟล์ `js/config.js` เก็บแค่ Publishable key ซึ่งออกแบบมาให้อยู่ฝั่งหน้าเว็บได้ **ห้ามนำ service_role key มาใส่ในโปรเจกต์นี้**
- ถ้าเชื่อมต่อฐานข้อมูลไม่ได้ หน้าร้านจะใช้ข้อมูลสำรองใน `js/data.js` แทน (โหมดออฟไลน์ คำสั่งซื้อจะไม่ถูกบันทึก)

## โครงสร้างไฟล์
```
index.html, css/style.css      หน้าร้าน
js/config.js                   URL และ key ของ Supabase
js/api.js                      โหลดแค็ตตาล็อก + ส่งคำสั่งซื้อ
js/main.js                     ใส่เนื้อหาจาก CMS, ผูกการเลื่อนจอกับฉาก/สี
js/scene.js                    ฉาก 3 มิติ (Three.js)
js/shop.js                     การ์ดสินค้า ตะกร้า checkout
js/fx.js                       ลูกเล่นต่างๆ
js/data.js                     ข้อมูลสำรองเมื่อออฟไลน์
admin/                         หลังบ้าน CMS (index.html, admin.css, admin.js)
vendor/                        Three.js r160, supabase-js (เก็บในเครื่อง)
img/                           รูปเริ่มต้น
```

## หมายเหตุ
- ราคาและโปรโมชันเป็นตัวอย่าง แก้ได้จากหลังบ้าน
- ภาพและเครื่องหมายการค้าเป็นของเจ้าของแบรนด์ LOVEZA! ใช้เพื่อการศึกษา
- ฉาก 3 มิติใช้สินค้าที่ติดดาว “แนะนำ” สูงสุด 8 ชิ้น รูปพื้นโปร่งใส (PNG/WebP) จะลอยสวยที่สุด
- อันดับขายดีมาจากฟังก์ชัน `best_sellers` ซึ่งรวมยอดจากคำสั่งซื้อที่ไม่ถูกยกเลิก
- ในฐานข้อมูลมีคำสั่งซื้อตัวอย่าง (เลขที่ขึ้นต้นด้วย `DEMO-`) ไว้ให้ส่วนขายดีและแดชบอร์ดมีข้อมูลแสดง ลบได้จากเมนูคำสั่งซื้อ
- รูปสินค้าหมวดอื่นนอกจากเครื่องดื่มเป็นภาพประกอบตัวอย่างใน `img/products/` ให้เปลี่ยนเป็นรูปจริงได้จากหลังบ้าน
